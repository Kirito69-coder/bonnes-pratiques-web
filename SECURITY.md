# Signaler un problème de sécurité

Ce dépôt contient principalement de la documentation et des exemples. Si vous découvrez un secret exposé, une vulnérabilité dans un exemple ou un problème pouvant entraîner une mauvaise pratique dangereuse, merci de ne pas publier d’informations sensibles dans une issue publique.

Ouvrez une discussion privée auprès du mainteneur du dépôt ou utilisez la fonctionnalité de signalement privé de GitHub lorsqu’elle est activée.

Ne joignez jamais de mot de passe, clé API, token, donnée personnelle ou preuve contenant des informations confidentielles.
