# Code de conduite

Ce dépôt adopte le Code de conduite de la Fondation Contributor Covenant version 2.1.

## Notre engagement

Nous nous engageons à fournir un environnement de contribution accueillant et sans discrimination pour tous, quel que soit l’âge, le corps, l’handicap, l’origine ethnique, les caractéristiques genétiques, l’identité et l’expression de genre, le niveau d’éducation, la nationalité, l’origine, la race, la religion, le métier, l’orientation sexuelle ou toute autre caractéristique protégée par la loi.

## Standards

Des exemples de comportements contribuant à la création d’un environnement positif :

- utiliser un langage inclusif et accueillant ;
- respecter les points de vue et expériences différents ;
- accepter avec courtoisie les commentaires constructifs ;
- se concentrer sur ce qui est le mieux pour la communauté ;
- faire preuve d’empathie envers les autres membres de la communauté.

Des exemples de comportements inacceptables :

- l’utilisation de langage ou d’images sexualisés, ainsi que tout acte de harcèlement sexuel ;
- le troll, les attaques personnelnelles ou morales et les insultes ;
- la publication de contenus privés tels que les adresses de messagerie ou les données de contacts sans autorisation explicite ;
- les représailles contre d’autres pour avoir signalé un comportement ou un commentaire inapproprié ;
- le fait de promouvoir ou de demander des activités illégales ou contraires à l’éthique.

## Responsabilités des mainteneurs

Les mainteneurs de ce projet sont responsables de faire respecter ces principes de manière claire et constante. Chaque fois que vous voyez un comportement inapproprié, agresseur ou bâclé, vous êtes tenu d’agir pour le signaler.

## Portée

Ce code de conduite s’applique à la fois dans les espaces du projet et dans les espaces publics lorsqu’une personne représente le projet ou sa communauté. Les représentants de projet comprennent l’utilisation de l’identité du projet (nom, logo, pseudonymes) dans les offres de conférence, les dépôts, les publications en ligne, les comptes sur les réseaux sociaux ou autres.

## Enforcement

Les cas de comportements inacceptables peuvent être signalés à un mainteneur cette adresse : security@monsite.com. Toutes les accusations seront examinées et investiguées, et ces dernières se solderont par une décision donnée à l’auteur concerné par la suite à l’amiabilité. Tous les messages de ce type seront traités de manière confidentielle. Seul le mainteneur peut décider de la sanction visant à rétablir la sécurité de la communauté.

Cette politique se veut claire, mais pas exhaustive. Elle n’est pas une consultation juridique.
