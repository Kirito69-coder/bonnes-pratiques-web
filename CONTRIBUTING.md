# Contribuer

Merci de contribuer à cette checklist de bonnes pratiques Web.

## Types de contributions acceptées

- correction d’une erreur technique ou typographique ;
- amélioration d’un exemple de code ;
- ajout d’une recommandation vérifiable et contextualisée ;
- ajout ou amélioration d’une traduction ;
- signalement d’une recommandation obsolète ou ambiguë.

## Avant de proposer une modification

- Vérifiez que la recommandation n’est pas déjà présente.
- Expliquez le problème concret qu’elle résout.
- Évitez les affirmations absolues lorsqu’une recommandation dépend du contexte.
- N’ajoutez jamais de secret, identifiant, donnée personnelle ou contenu sous copyright sans autorisation.
- Pour les sujets juridiques, indiquez le pays ou le périmètre concerné et privilégiez les sources officielles.

## Pull request

Une pull request devrait décrire :

1. le problème ou le besoin ;
2. la modification réalisée ;
3. le périmètre concerné ;
4. les éventuelles limites ou hypothèses.

Les exemples de code doivent rester lisibles, génériques et accompagnés d’un avertissement lorsqu’ils ne sont pas prêts pour la production.
